# CLAUDE.md

Read this first, then the effect's header comment (each `.c` file fully describes its knobs and DSP). docs/EFFECTS.md has the user-facing detail.

## What this is
Eleven custom effects (WaveFold, DualShft, Choral, EuGate, DubSiren, S.GN_L, Scrub, DirtBox, Breather, GRDELAY, Sweep; v1.5 also had SyncEQ, dropped 2026-10-08), plus Looper (MIDISTOMP v2.0 step 1 test build, not released) for Zoom MS pedals, built as `.ZDL` with the toolchain from themanro/ZoomMultistompZDL (`build/`). Owner's pedal: MS-60B on MS-50G firmware; other pedals untested. Effects are for synths/drums, never guitar.

## Layout

- `src/custom/<effect>/`: `<effect>.c`, `manifest_pedal.json` (knobs, ranges, defaults, fxid), `make_cover.py`, `build.py`. Choral is in `formant/`, S.GN_L in `sgnl/`.
- `src/airwindows/common/covers/*.json`: generated by `make_cover.py`, loaded by `custom_covers.py`.
- `tests/`: host tests (`python3 tests/run.py [name]`). `release/`: pack README, cover sheet; `make_release.py` zips `dist/*.ZDL`.
- fxids: DualShft 480, DubSiren 485, Choral 486, WaveFold 487, EuGate 488, S.GN_L 489, Scrub 490, DirtBox 491, Breather 493, GRDELAY 495, Sweep 496, Looper 497; new: LOUDER 481, DJFilter 502 (484 clashes with Gyre), Washout 492, Takeoff 494, Gooey 501, GooeyMB 947 (free across collections, themanro FXID-REGISTRY) (all in Delay 8, as in beta1; renumbering is a proposal for after v2.0, docs/EFFECT-IDS.md).
- `src/probes/<probe>/`: hardware probes, never released, built only when named (TempoPrb fxid 499, DryPrb fxid 498, RoutePrb fxid 500).
- S.GN_L: `effect_name` SGNL (file, symbols, SONAME); `display_name` S.GN_L only in the descriptor name entry.
- Docs: `docs/SAFE-DSP-RULES.md` (C rules), `docs/DECISIONS.md` (owner decisions per effect), `docs/COVERS.md` (cover rules), `docs/TEMPO-SYNC.md` (section 10 = MOD firmware transport), `docs/EFFECTS.md`.

## Building and testing
The TI C6000 compiler is only on the owner's Windows PC; the cloud can't build `.ZDL`. The owner runs `py build_all.py <effect>` (or his `build_<effect>.bat`) and loads `dist\<Name>.ZDL` with Zoom Effect Manager. Claude handles source, manifests, covers and host tests; run `python3 tests/run.py` after any DSP change and say plainly what was and wasn't tested (no listening test, CPU never measured).

## C code rules (each caused a real failure, or see docs/SAFE-DSP-RULES.md)

- No float-to-unsigned casts (`__c6xabi_fixfu` unresolved): write `(unsigned int)(int)(x)`.
- No libm; use helpers (`wf_rsqrt`, `exp2_oct`). Avoid float division and all integer division/modulo.
- No `switch`, no static/const arrays in `.audio`, no `double`, no `long long`. Helpers are `*_ALWAYS_INLINE`.
- Never write the Dry buffer (ctx[4]).
- `effect_name` max 8 chars.
- Knobs arrive as (screen value)/100; convert back like `sr_knob`, `ch_ui`, `wf_knob`. Read Scrub's Pos as raw x 100, never through the 3.05 guess.
- `ZDL_GetLabel_N` sees only its own knob; encode dependencies in the range (e.g. 101..112 = note values).
- State lives in the arena, validated by a magic number: change the magic when the struct changes.
- Keep the 8-sample block structure: knob reads and `prepare` once per block, then the sample loop.

## Conventions
- Mix = DJ crossfade (dry min(1,2-2m), wet min(1,2m)); DubSiren has Vol and Breather Depth/Verb instead of Mix.
- Tempo effects target the custom firmware (MOD 0.4+) only: no Tempo knob; BPM, MIDI Start and the clock count come from `src/custom/common/zmt.h` (`zt_update` once per block); lock synced phases to `beats` while running, restart on Start, run free after Stop; main synced knob has manifest `"flags": 40` (tap button). Test with `tests/transport.h`.
- Covers: see docs/COVERS.md. Owner decisions: see docs/DECISIONS.md (don't undo).
- Change a knob or behaviour: update header comment, manifest, docs/EFFECTS.md, README, release/README.md in step.
